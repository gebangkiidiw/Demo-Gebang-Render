# Demo Gebang Render — UI Snowcase

Halaman showcase statis untuk produk **Gebang Render (1-Klik Album Video)**.

Hanya HTML + CSS + sedikit JS untuk interaksi UI (ganti halaman, toggle tema gelap/terang, collapse sidebar). Tidak ada backend, Electron, atau API call.

## Cara pakai

- Buka `index.html` langsung di browser, atau
- Aktifkan GitHub Pages di repo ini untuk akses online

## Tema

- **Default:** gelap (crimson + ember, glassmorphism)
- Toggle manual: klik ikon bulan/matahari di header kanan atas

## Logo

Taruh `logo.png` (atau `app-icon.png`) di root repo agar tampil di sidebar.
