Help

Panduan singkat memakai Gebang Render.

Cara pakai dalam 4 langkah

  1. Siapkan video loop — satu file MP4/MKV/MOV apa pun yang mau dipakai sebagai visual berulang.
  2. Siapkan folder audio — kumpulan file MP3/WAV hasil generate Gebang Lagu (atau sumber lain). Urutan file = urutan trek di album.
  3. Pilih encoder — kalau ada GPU NVIDIA/Intel/AMD, otomatis terdeteksi. Tidak ada GPU? Otomatis pakai CPU (libx264).
  4. Klik Mulai Render — tunggu sampai selesai. Hasil: satu file MP4 utuh + Timestamp.txt siap salin ke deskripsi YouTube.

Tips & praktik terbaik

  • Resolusi video loop idealnya sama dengan output target — tidak ada upscaling yang membuang-buang waktu.
  • Encode dengan NVENC P5 sudah cukup untuk YouTube; P7 hanya menambah ukuran file tanpa perbedaan visual signifikan.
  • Anti-duplicate Ken Burns membuat setiap trek punya gerakan visual berbeda → aman dari deteksi reused content.
  • -14 LUFS adalah standar YouTube Music; pilih -16 LUFS kalau tujuannya Spotify/Apple Music.
  • Gapless OFF hanya untuk kasus khusus (mis. mau ada jeda 0.5 detik antar trek untuk video podcast).
  • Folder output default bisa diganti di Settings · Preferensi render.
  • Lisensi aktivasi sekali per perangkat — uninstall aplikasi tidak menghapus lisensi (tetap tersimpan di config).
